# 📅 2026-05-25 리팩토링

> MinimapUI 개선


```c++
## 📂 대상 파일 / 모듈
- MinimapBase.cs
- MinimapUI.cs
- FixedMinimaUI.cs
- ViewOnlyMinimapUI.cs

## 🔍 리팩토링 전 (문제점)
- 현재 미니맵 시스템은 MinimapBase를 상속받는 구조로 되어있는데 MinimapUI는 줌인/줌아웃, 드래그,
  토글, 플레이어 도트 등 모든 기능을 가지고 있고, ViewOnlyMinimapUI는 플레이어 도트 표시만 있는
  읽기 전용 미니맵이다. 팀원 요청으로 제작UI 옆 미니맵에 줌인 기능을 추가하려고 보니 기능이 MinimapBase를
  상속받은 클래스 단위로 묶여있어서 부분 재사용이 안되는 구조였다. 결국 줌인 기능 하나 추가하려고 
  MinimapBase를 상속받은 새로운 클래스를 만들어야 하는 상황이 생겼고 이런식으로 기능 조합이 필요할 
  때마다 클래스가 계속 늘어나는 확장성과 재사용성이 떨어지는 구조라는걸 발견했다.


## ✅ 리팩토링 후 (개선 내용)
- MinimapBase를 상속받는 상속구조를 제거 하고 MinimapElement를 관리하는 MinimapUI 단일로 존재하도록
  개선했다.
- MiniamapBase를 상속받아서 제작되었던 각 미니맵에 존재하던 기능들을 컴포넌트로 분리할 것이다(MinimapZoom,
  MinimapPlayerDot, MinimapFollow, MinimapToggle, MinimapDrag등).

## 💡 배운 점 / 메모
- 기존에 Minimap구조를 잡으면서 이런 문제가 터질거라고 생각을 못했지만 막상 이런 문제점을 발견하고
  리팩토링 하니 좀더 확장성과 재사용성 있게 개선하고 있는거 같아 기분이 좋다.
```
